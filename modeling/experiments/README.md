# Rejected surface study, 2026-10-06

`rejected_surface_study.py` explored a photo-informed parametric exterior workflow for the remaining seven body families. The LS 400 trial failed visual review in two iterations. It was not published as a vehicle asset and was not propagated to the other six models.

Observed failures: disconnected upper skins in iteration 1; overly generic fascia; inaccurate lamps and wheel faces; roof/window transitions that did not reproduce the OEM geometry; no authentic panel topology. Iteration 2 corrected the clamped hood profile but introduced glass occlusion and still failed vehicle identity. These are substantive geometry errors, not issues that realistic textures can solve.

The experiment is retained to record the failed approach. Do not run it to populate the catalog or mark any output as a completed Lexus model. The catalog source audit and acquired CC BY models are the active work.
